# RPS Builder v2 (web)

Next.js + Supabase. Spesifikasi: SRS RPS Builder v2 (v1.0, 12 Nov 2026).

- Variabel lingkungan: lihat `.env.example` (di Vercel: Settings > Environment Variables).
- Vercel: Root Directory = `web`.
- Aplikasi hanya memakai anon key + sesi pengguna; jangan pernah menaruh service_role key di sini.
- Uji lokal: `npm run build` lalu `npm start`.
